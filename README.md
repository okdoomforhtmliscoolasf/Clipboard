# ClipBoard — Project 002
A local-first visual reference manager built with vanilla HTML, CSS and JavaScript.

## Features
- Save links, image references, notes and ideas
- Custom boards and tags
- Search, type filters and sorting
- Favourites and recently added view
- Edit and delete clips
- Optional image previews
- JSON backup export/import
- Light/dark appearance
- Responsive layout

## Run
Open `index.html` in a modern browser. No build tools or server required.

## Publish with GitHub Pages
1. Create a repository named `clipboard`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Commit.
4. Go to Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## Storage
Data is stored in this browser's localStorage. It does not sync between devices. Export a backup regularly.
